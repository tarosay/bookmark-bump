# bookmark-bump
Automatically move recently used bookmarks to the top of selected folders.

BookmarkBump は、使ったブックマークを、そのブックマークがあるフォルダの先頭側へ自動で移す Firefox アドオンです。
並べ替えるかどうかは、フォルダごとに右クリックで切り替えます。Firefox のブックマークの使い方は、今までと変わりません。

## 使い方

1. ブックマークツールバー、ブックマークメニュー、サイドバーなどで、**フォルダ**を右クリックする
2. 「**使用したブックマークを先頭に移動**」にチェックを入れる
3. あとは普段どおりにブックマークを使うだけです。開いたブックマークが、そのフォルダの先頭側へ移ります

- 最初はすべてのフォルダが OFF です
- 設定はフォルダごとに独立しています。親フォルダを ON にしても、中のサブフォルダは OFF のままです
- チェックを外すと、そのフォルダはそれ以降並べ替えません（並び順は元に戻りません）

## 並べ替えのルール

```text
📁 フォルダA [ON]                    📁 フォルダA [ON]
  📁 サブフォルダ1                     📁 サブフォルダ1
  📁 サブフォルダ2        GitHub        📁 サブフォルダ2
  🔖 Google              を開く  →     🔖 GitHub
  🔖 GitHub                            🔖 Google
  🔖 Mozilla                           🔖 Mozilla
```

- 使ったブックマークは、サブフォルダ群のすぐ後ろに移ります。ほかのブックマークの順序は変わりません
- サブフォルダは常にブックマークより上にまとめます。サブフォルダ同士の順序は変えません
  （フォルダを ON にした時点で、散らばっているサブフォルダを上にまとめます）
- ブックマークの名前・アドレス・所属フォルダは変えません
- **区切り線がある場合**は、区切り線をまたいで動かしません。区切り線で分かれた範囲ごとに、上のルールで並べ替えます

## 「使った」とみなす条件

ON のフォルダにあるブックマークと**同じアドレスのページを開いたとき**に、そのブックマークを先頭へ移します。
ブックマークから開いた場合に限らず、履歴・アドレスバー・ページ内のリンクから開いた場合も同じです。

Firefox は、どのブックマークがクリックされたかをアドオンに知らせません。そのため、開いたページのアドレスで判断しています。

- 同じアドレスのブックマークが複数あるときは、ON のフォルダにあるものだけが移ります（OFF のフォルダのものは動きません）
- 別のアドレスへ自動で移るサイト（`http://` → `https://` など）は、開き始めのアドレスでも照合します
- アドレスの末尾の `/` の有無は区別しません（Firefox の検索と同じ）

## インストール（一時的な読み込み）

署名済みの配布版はまだありません。開発中は次の方法で読み込みます。Firefox を閉じると外れるので、起動のたびに読み込み直してください。

1. Firefox のアドレスバーに `about:debugging#/runtime/this-firefox` と入力して Enter
2. 「一時的なアドオンを読み込む…」を押す
3. このリポジトリの `manifest.json` を選ぶ

一時的な読み込みの場合、Firefox を再起動して読み込み直したあとにフォルダの ON/OFF 設定が残るかは、まだ確認していません。

## 既知の制約

- ページ単位で判断するので、ブックマーク以外から開いた場合も並べ替わります（上記「使った」とみなす条件）
- ページの中だけで表示が切り替わるサイト（ページの読み込みを伴わない移動）は、移動先のアドレスがブックマークにあっても並べ替えません
- プライベートウィンドウでは、Firefox のアドオン管理画面で「プライベートウィンドウで実行」を許可しない限り動きません
- 必要な Firefox: 115 以降

## 開発・テスト

```bash
npm test
```

Node.js 18 以降が必要です（外部ライブラリは使いません）。テストは次の 2 種類です。

- `test/reorder.test.js` … 並べ替えの順序の計算
- `test/background.test.js` … Firefox の API をまねた偽物の上で、ON/OFF・同一アドレス・リダイレクト・設定の保存・フォルダ削除などを確認

偽物の API でのテストなので、本物の Firefox での動作確認の代わりにはなりません。

### ファイル構成

| ファイル | 役割 |
|---|---|
| `manifest.json` | アドオンの定義 |
| `src/background.js` | ページを開いたときの処理、右クリックメニュー、設定の保存 |
| `src/reorder.js` | 並べ替えの順序を計算する |
| `icons/icon.svg` | アイコン |
